Rack Upright Capacity Tool

Axial-compression screening calculation — Eurocode 3 flexural-buckling method

Design basis and limitations

Not a complete rack-upright design check. This tool implements a transparent, generic EC3 flexural-buckling screening calculation only. Perforated cold-formed rack uprights require rack-specific treatment and/or testing under EN 15512. Do not use this result as certified rack capacity.
  • Implemented: Euler flexural buckling and EN 1993-1-1 §6.3.1.2 reduction-factor method, with user-selected imperfection factor b1 and b3M1.
  • Not implemented: effective-section properties, local/distortional buckling, holes/perforations, torsional or flexural–torsional buckling, residual stresses, upright testing/calibration, beam connection restraint, base stiffness, global rack analysis, load eccentricity, and P–94 effects.
  • Rack standard context: EN 15512:2021+A1:2022 includes specific provisions for perforated compression members, flexural buckling, and torsional/flexural–torsional buckling. These are deliberately not inferred from the limited input set.

The user must select b1 from the applicable buckling curve and national annex; the default is an explicitly labelled provisional assumption, not a rack-upright provision.

Inputs

For asymmetric restraint, use separate Lcr,x and Lcr,y in a validated version; this simplified tool applies the same entered Lcr to both axes.

Formulas used

Unit conversions: A[mm²] = 100 A[cm²]; I[mm⁴] = 10⁴ I[cm⁴]; L[mm] = 1000 L[m] Euler load: Ncr,i = π² E Ii / Lcr² (i = x, y) Non-dimensional slenderness: λ̄i = √(A fy / Ncr,i) Φi = 0.5 [1 + αi(λ̄i − 0.2) + λ̄i²] χi = min{1, 1/[Φi + √(Φi² − λ̄i²)]} Nb,Rd,i = χi A fy / γM1 Nb,Rd = min(Nb,Rd,x, Nb,Rd,y) Utilization = NEd / Nb,Rd Source: EN 1993-1-1:2005+A1:2014, §6.3.1.2, Eq. (6.49)–(6.53), subject to its scope and cross-section applicability.

Engineering interpretation

Required review before design use

Obtain qualified perforated-upright test data or a complete EN 15512 procedure. Confirm effective/net area, local and distortional modes, torsional/flexural–torsional modes, axis-specific effective lengths, connection/base restraint, global rack stability and second-order effects.
